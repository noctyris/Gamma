# Support

## Where to ask

- **Bug or unexpected behaviour**: open an issue with the bug report template.
- **Installation or build problem**: open an issue with the installation template
  and include the exact command and error.
- **Question or feature discussion**: use GitHub Discussions or the question
  template.
- **Security issue**: follow [SECURITY.md](./.github/SECURITY.md); do not open a
  public issue.

## Information to include

Always include:

- the Gamma version (`Settings > About > Gamma version`);
- the Gamma commit (`Settings > About > tap the Epsilon version once`);
- the device or simulator target;
- the build command, if you built Gamma yourself;
- the exact error message or a screenshot.

## Before opening an issue

1. Read the [README](./README.md) and the build instructions.
2. Search existing issues and discussions.
3. Try a clean build (`make cleanall`) if the problem looks like a stale build.
4. Check that you are on `gamma-dev` or a released version, not an old fork.

## Out of scope

Gamma cannot provide support for official NumWorks firmware, for calculators
modified by third parties, or for binaries built from unknown sources.
