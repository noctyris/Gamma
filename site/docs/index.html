Build and install Gamma

Gamma is based on the public Epsilon 15.5.0 sources. It does not include code from Epsilon 16.0.0 or later, which NumWorks publishes under “All rights reserved”.

Requirements

On Debian or Ubuntu:

sudo apt-get install build-essential git imagemagick \
  libx11-dev libxext-dev libfreetype6-dev libpng-dev libjpeg-dev \
  pkg-config gcc-arm-none-eabi binutils-arm-none-eabi

Then clone the repository with its submodules:

git clone --recursive https://github.com/noctyris/Gamma.git
cd Gamma
git checkout gamma-dev

Linux simulator

make PLATFORM=simulator TARGET=linux -j"$(nproc)"
make PLATFORM=simulator TARGET=linux test -j"$(nproc)"
./output/release/simulator/linux/test.bin --headless

Web simulator

Install emsdk 4.0.22, activate it, then run:

make PLATFORM=simulator TARGET=web htmlpack.zip -j"$(nproc)"

n0110 with the Gamma bootloader

make MODEL=bootloader GAMMA_USERNAME="Your name" -j"$(nproc)"
make epsilon.A_flash

The bootloader keeps two slots. Flashing slot A or B leaves the other slot intact. Use a USB cable and follow the DFU instructions printed by the build.

n0100

make MODEL=n0100 EPSILON_I18N=en GAMMA_USERNAME="Your name" -j"$(nproc)"
make MODEL=n0100 epsilon_flash

n0100 supports one language only and does not include Reader, Atomic or ulab.
