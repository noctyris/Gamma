A community OS for NumWorks calculators.

Gamma continues the Epsilon 15.5.0 lineage with themes, wallpapers, external apps, a redesigned Functions app and many quality-of-life improvements.

What is inside

Epsilon 15.5.0 base

Stable, public and licensed under CC BY-NC-SA 4.0.

Gamma themes

Light and dark themes, wallpapers and a theme engine.

Apps that matter

RPN, Atomic, Reader and external applications.

Bootloader slots

Safe A/B installation on supported n0110 calculators.

Run Gamma in your browser

The simulator is built from the current release branch. Click the screen first, then use your keyboard. On touch devices, use the on-screen keys.

Install on a calculator

Read the build and installation guide first. A firmware has full access to the calculator: only flash binaries you built yourself or downloaded from this repository's releases.
