work of Omega and Upsilon, which were themselves based on NumWorks Epsilon.

## Epsilon 16.0.0 and later

Starting with Epsilon 16.0.0, the upstream NumWorks repository no longer contains
a `LICENSE` file and its README states:

Gamma is based on the public Epsilon 15.5.0 sources and does not import code from
Epsilon 16.0.0 or later. Do not copy code from those versions into Gamma without
written permission from NumWorks.

This notice is factual information about the upstream repository, not legal
advice. If you intend to redistribute Gamma or a modified version, verify the
